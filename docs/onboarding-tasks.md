# 新人练手：vla-harness + RobotWin 出分（最小闭环，0-1 切分版）

> 原则：只给目标和验收，不给步骤不给链接。卡住了先自己想办法；
> 实在过不去带着“已试过的三条路”来问人。红线见末尾。

## T1. 机器分工（W2，熟悉期）

- [ ] T1.1 任选机器数量并部署到位，能远程开关机
  - 验收：关机→开机→runner 上线→关机，全流程走通一遍
- [ ] T1.2 证明你的分工能撑住一次完整评测（不断网、不掉线）
  - 验收：连续跑通 1 个 smoke（任务不限）

## T2. 镜像同步（W2-W3，机械活）

- [ ] T2.1 把 1 个评测镜像同步到内网仓
  - 验收：内网仓出现该 tag，且 digest 与源一致
- [ ] T2.2 把 1 个 serve 基础镜像同步到内网仓
  - 验收：同上

## T3. 部署架构设计 + 镜像打包（W4-W6，最难，给 3 周）

- [ ] T3.0 先画图再动手：输出部署架构设计（镜像分层、仓策略、编排、守卫；最差照搬官方也算过关）
  - 验收：有一份设计文档；完工后对照一次（看哪些被现实推翻了）

## T3. 镜像打包（续）（W4-W6，最难，给 3 周）

- [ ] T3.1 自行设计 serve 镜像内容（加什么自己定），打出来
  - 验收：镜像存在且可启动（先不要求能评分）
- [ ] T3.2 用自烘镜像起服，端口通，响应一次空请求
  - 验收：日志出现 UP；说清权重来源与加载路径

## T4. 联调测试（W7）

- [ ] T4.1 仿真端与 serve 端连通（一次握手）
  - 验收：一次 run 能发出请求并收到动作（对错不管）

## T5. 出分测试（W8，收尾）

- [ ] T5.1 跑完 1 个 task×1 集，拿到 mean_success（不问多少分）
  - 验收：指出分数落盘位置与字段
- [ ] T5.2 复述数据流向（仿真→判分→落盘→上报），并指认每一步对应的组件
  - 验收：说对即可，不考细节

## 红线（碰了就回滚+写检讨）

1. 不删内网仓的任何 tag
2. 不在 V100 上手装任何东西
3. GPU 一次只跑一个任务
