# 新人练手：vla-harness + RobotWin 出分（最小闭环）

> 原则：只给目标和验收，不给步骤不给链接。卡住了先自己想办法；
> 实在过不去带着“已试过的三条路”来问人。红线见末尾。

## W1-W2：机器与网络

- [ ] T1. 技术栈设计：几台机器、怎么分工、约束是什么，自己定
  - 验收：画出分工图并答辩——为什么是这个数量（2 台行不行？3 台多在哪？），每台的网络边界与禁止事项，违反一条什么后果

## W3-W4：镜像打包

- [ ] T2. 镜像同步：把评测镜像与 serve 基础镜像同步到内网仓并拉取验证
  - 验收：内网仓出现所需 tag；说清 tag 钉死策略，不用 latest 的原因
- [ ] T3. 镜像打包：自行设计并烘焙 serve 镜像（内容自定），推送内网仓
  - 验收：用自烘镜像起服成功；能讲清每一层的作用及删除后果

## W5-W6：联调测试

- [ ] T4. serve 联调测试：端口通，响应一次空请求
  - 验收：日志出现 UP；说清权重来源与加载路径

## W7-W8：出分测试

- [ ] T5. 跑完 1 个 task×1 集，拿到 mean_success
  - 验收：指出分数落盘位置与字段；复述数据流向（仿真→判分→落盘→上报）

## 红线（碰了就回滚+写检讨）

1. 不删内网仓的任何 tag
2. 不在 V100 上手装任何东西
3. GPU 一次只跑一个任务
