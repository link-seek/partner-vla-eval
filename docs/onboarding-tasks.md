- [ ] T4.3 通读仓里所有的讨论帖，列出你认为最重要的 3 条教训并说明为什么

## 红线（碰了就回滚+写检讨）

1. 不删 SWR tag（0.7.0 保留是决策，不是疏忽）
2. 不在 V100 上手装任何东西（缺工具→改 Dockerfile 走流水线）
3. 不改 harness 上游代码（要改走 vendoring 挂载 + 版本钉死）
4. GPU 一次只跑一个（pending 会被新触发挤掉，已验证 3 次）
