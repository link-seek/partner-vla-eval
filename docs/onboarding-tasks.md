# 新人练手：vla-harness + RobotWin 出分（最小闭环）

> 原则：只给目标和验收，不给步骤不给链接。卡住了先自己想办法；
> 实在过不去带着“已试过的三条路”来问人。红线见末尾。

## W1-W2：机器能动

- [ ] T1. 开关机走一遍：机器从关到开，runner 上线，再关掉回到关机
  - 验收：说出三台机器各自能干什么、不能干什么

## W3-W4：镜像能跑

- [ ] T2. 把评测镜像同步到内网仓，再从内网拉下来跑起来（任选其一：benchmark 或 serve）
  - 验收：`docker images` 里有它，且说出 tag 为什么不能用 latest

## W5-W6：模型能服

- [ ] T3. 自己设计并烘焙一个 serve 镜像，加什么、为什么加，自己定；然后用它起服，端口通
  - 验收：用自烘镜像跑出分；能讲清镜像里每一层是干嘛的、删掉哪层会炸

## W7-W8：出分

- [ ] T4. 跑完 1 个 task×1 集，拿到 mean_success（不问多少分，问分从哪来）
  - 验收：指出分数写在哪个文件、哪个字段，并复述一遍数据流向（仿真→判分→落盘→上报）

## 红线（碰了就回滚+写检讨）

1. 不删内网仓的任何 tag
2. 不在 V100 上手装任何东西
3. GPU 一次只跑一个任务
