## 02 已建成（1.5 分钟）

> 三件别人通常没有的事。
>
> 第一，**能对上官榜**。X-VLA 跑 RoboTwin 50 个 task，我们是 66.56%，官方 67.96%，差 1.4 个点。这个数字由校准门自动守——不是嘴上说接近，是每次提交都验。
>
> 第二，**能复现**。协议版本、镜像 digest、逐集种子表都钉住；每一格都能追到 run、aggregate、sqlite 和原始逐集产物。出争议时，不用再吵"是不是你机器的问题"。
>
> 第三，**能接别人接不了的模型**。官方 ACT 和 DP 的公开权重我们都接上了，各跑 50 集参考：ACT 46/50，92%；DP 40/50，80%。
>
> 再加上 18 道门，坏结果不进表。所以我的判断是：**基础设施已经不是瓶颈。**

## 03 为什么必须自己做（2 分钟）

> 这一页回答一个一定会被问到的问题：平台都自带评测了，为什么还要自己做？
>
> 拿华为云 CloudRobo 的公开文档做样本。先说它的强项：一站式，数据评测也比我们深——安全、效率、平稳性三维，二十多个指标，还出 PDF 报告。这一点我们不如它。
>
> 但模型评测这一环，它的默认值决定了我们的题测不了。
>
> **第一，考场。** 任务集只接了 LIBERO，RoboTwin 不在列表里，我们的 50 个 task 它不收。
>
> **第二，时长。** 每轮超时上限 300 秒，默认 90。我们 handover_block 一个 episode 要 80 分钟，第 91 秒就被砍，成功率恒等于 0——错的不在模型。文档里也没给工单放宽的路径。
>
> **第三，读数。** 它只给成功率和耗时，没有 error 分类、没有置信区间、没有多种子。我们每一格都带 n、errors、95% CI 和平均步数。
>
> 所以结论不是"平台不行"，是**两种解法**：平台答这套资产能不能用，我们答这个模型多少分、这个分可不可信。这就是模型评测必须自己做的原因。

## 04 最诚实的缺口（1.5 分钟）

> 但我要把风险写实，不然这页就是广告。
>
> 第一，**外部引用是 0**。AI 独立读者只是临时证据，不是真人验收。所有东西都还是自证。
>
> 第二，**统计力不够**。n=50、单轮，噪声带约 ±8 个点。现在只能回答"这个配置多少分"，回答不了"模型 A 是否真的比 B 好"。采购和验收要的恰恰是后者。
>
> 第三，**数据质量维度薄**。S1 只有格式校验和统计——2750 个文件、38 万帧、0 坏文件；安全、效率、平稳性还没建。
>
> 第四，**成本线性**。20 个 ckpt 大约 7.5–11 天、6000 到 8700 块，没有规模效应之前，每加一个模型都是线性成本。
>
> 所以：**继续加门禁的边际收益，已经低于找第一个真实用户。**

## 05 下一步只做三件事（1.5 分钟）

> 第一，**找第一个真实引用**。一次合作方验收、一次采购比对、或者一次榜单提交，都行。交付一份对方愿意引用的可复现报告。
>
> 第二，**补重复轮 r2**。先在一个模型、一个 task 上把显著性口径跑通，让报告能从"这个配置多少分"升级到"这个差异是否显著"。预算很小，试验大约 20 块。
>
> 第三，**借数据三维**。安全、效率、平稳性，维度名先复用，阈值按 RoboTwin 的数据分布自己校准。CloudRobo 没做这件事，正是我们的空间。
>
> 明确不做：不再加门禁、不再堆文档、不正面做"大而全平台"。把资源集中到"第一次被采用"。

>

# Q&A 预案

| 追问 | 怎么答 |
|---|---|
| 为什么不自建一个大而全平台？ | 平台是重资产路线；我们先占"可采信的尺子"这个位置。第一个外部引用跑通后，再决定是否产品化。 |
| CloudRobo 不是也能评吗？ | 能评"能不能用"，不解决 RoboTwin 覆盖、长程任务、显著性和官榜校准。我们不是替代平台，是补可比性这一层。 |
| 300 秒是不是绝对不能解除？ | 文档没有给放宽路径，API 是取值校验；但原文"该时长将重置"有歧义，是否硬截断要实测。材料里写的是"文档未给路径"，不说"不可解除"。 |
| 为什么 18 道门还不够？ | 门禁解决的是"坏结果别进来"，不解决"有没有人用"。现在是后者缺，不是前者缺。 |
| n=50 为什么不够？ | 单轮 n=50 的噪声带约 ±8pp；没有重复轮，不能把点估计差异当成显著差异。r2 就是补这一刀。 |
| 数据质量三维抄别人会不会同质化？ | 维度名是公共度量语言；阈值按 RoboTwin 数据分布校准，报告与我们的任务/模型闭环绑定，才是差异。 |
| 最大风险是什么？ | 不是技术失败，是一直没有外部用户。供给端 80 分，需求侧 0 分。 |
