# 汇报方案：建设专业评测能力

> 目标：一次技术评审汇报，讲清"我们建了什么能力、站在第几根柱子上、还差什么"。
> 受众：熟悉 VLA 评测的工程/研究同事。要求：克制、有证据、不越界解读。
> 交付物：一份 deck（12 页 + 2 页附录）+ 一页缺口清单。**5b 微调轴不进本次汇报**，标下一阶段。

---

## 一、先定三条规矩（决定后面所有取舍）

1. **只讲有证据的**：每个数字都要能指到 run 链接 / 机器实取 / 上游 PR。没跑出来的写"待补"，不写估算。
2. **能力优先，结果其次**：按"跑得起来 / 比得可信 / 尺子能修 / 口径分得清"组织，不按"我们跑了几个模型"组织。
3. **口径不越界**：CogACT（qpos，3 格）与 X-VLA（EE，5 格）只并列不排名；Hard 没跑就说没有。
