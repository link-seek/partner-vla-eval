## 流程（三步，有明确交付）

1. **smoke（1 天内）**：我们按表单起 serve，跑 1 个 task×1ep。
   输出：通/不通 + spec 对齐报告。名字会骗人，实测不会——口径不对这里打回，不烧大钱。
2. **全量（排期）**：smoke 通过后进 V100 队列，1 task×50ep。
   单卡约 3~7 小时/task，按 task 数排期。跑完关机，结果进 OBS。
3. **报告**：每个 task 的 `mean_success` + 录像 + 和官方口径的对照说明。
   跨榜不合成总分，并列展示。

## 时间参考（V100 单卡实测）

- smoke：半小时~2 小时（含环境准备）。
- 全量：3~7 小时/task。
- 排期按 task 数线性累加，串行。

## 会被打回的情况（Top 3）

1. 只给了模型名没给确切 commit（一名多版，复现必翻车）。
2. 权重下不了（要授权的先开好 HF 权限）。
3. 按 task 分头的只给了部分头（没头的 task 排不上）。
