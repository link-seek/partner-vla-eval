# 伙伴模型评测对接指导书

> 版本：v1.0（2026-10-14）。给来评测的伙伴看，不用懂我们内部链路。

## 你要准备什么（两样）

1. **权重地址**：HuggingFace id 或可下载链接。CogACT 这类“按 task 分头”的，
   每个 task 一个地址；单仓共享权重给一个就行。
2. **口径信息表**（照实填，不知道就空着，我们帮你看）：

| 项 | 例 | 说明 |
|---|---|---|
| 本体 | 双臂 Aloha / 单臂 Franka | 决定进哪个考场 |
| 动作空间 | 关节 14 维 / 末端 20 维 / 单臂 7 维 | **最关键**，错了必 0 分 |
| 相机 | 头/左腕/右腕？名字？ | 名字对不上直接黑图 |
| 状态 | 关节角 / 末端位姿 / 不需要 | 决定接哪个字段 |
| chunk | 一次出几个动作（如 16） | 和考场节拍对齐 |

## 流程（三步，有明确交付）

1. **smoke（1 天内）**：我们按你的口径起 serve，跑 1 个 task×1ep。
   输出：通/不通 + 第一条 spec 报告。口径不对这里打回，不烧大钱。
2. **全量（排期）**：smoke 通过后进 V100 队列，1 task×50ep。
   单卡约 3~7 小时/task，按 task 数排期。跑完关机，结果进 OBS。
3. **报告**：每个 task 的 `mean_success` + 录像 + 和官方口径的对照说明。
   跨榜不合成总分，并列展示。

## 时间参考（V100 单卡实测）

- smoke：半小时~2 小时（含环境准备）。
- 全量：3~7 小时/task。
- 排期按 task 数线性累加，串行。

## 会被打回的情况（Top 3）

1. 动作口径和考场对不上（EE 模型报双臂关节榜必 0 分，先改配置）。
2. 权重下不了（要授权的先开好 HF 权限）。
3. 按 task 分头的只给了部分头（没头的 task 排不上）。
