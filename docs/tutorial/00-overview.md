# 00 总览

> 版本：v1.0（2026-10-14，随 RobotWin 四轮收官）
> 口径源：本仓 Discussion #1 全帖；版本锁定见各章版本头。

## 我们在干什么

给伙伴模型做横向评测：同一套链路、同一口径出分。执行层用
`allenai/vla-evaluation-harness`（`vla-eval`），基准分考场跑，结果汇总后可攒成自己的榜。

## 选型三问（先答再动手）

1. 评什么能力？——单臂短程 / 单臂长程 / 双臂（真机后放）。
2. 模型什么口径？——关节（CogACT）还是末端位姿（X-VLA）？口径错了必 0 分（见 08）。
3. 分数跟谁比？——只跟官方同种子口径比，不跨榜加权（见 07）。

## 术语表

| 词 | 意思 |
|---|---|
| 考场 | 一个 benchmark：仿真环境 + 任务集 + 判分规则 |
| 口径 | 观测/动作的数据格式（关节角 vs 末端位姿、维度、帧率） |
| smoke | 1 task×1ep，只验链路不计分 |
| 全量 | 1 task×50ep（`test_num` 官方口径），计分 |
| 分片 | `run_sharded.sh -n N` 并行跑，结果进同一 SQLite |
| 校验种子 | 上游自带的验证种子集（0.8.0 `expert_seeds/`），坏种≈0 |
| 盲种子 | 按 seed 顺序硬跑，坏种记 error |
